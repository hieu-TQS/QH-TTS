# QuangHieu TTS Studio

![Logo](https://raw.githubusercontent.com/hieu-TQS/QH-TTS/main/Logo.png)

**QuangHieu TTS Studio** là phần mềm chuyển đổi văn bản thành giọng nói tiếng Việt, chạy trên máy tính cá nhân, hỗ trợ clone giọng nói và tạo âm thanh chất lượng cao.

## Giới thiệu

Phần mềm giúp bạn nhập văn bản và xuất file âm thanh giọng nói tiếng Việt tự nhiên. Ứng dụng có giao diện đồ họa dễ sử dụng, hoạt động offline, phù hợp cho podcast, video và các nhu cầu đọc văn bản tự động.

## Tính năng chính

- Chuyển đổi văn bản tiếng Việt thành giọng nói tự nhiên
- Clone giọng nói từ audio mẫu
- Xuất file âm thanh chất lượng cao
- Giao diện đồ họa thân thiện, dễ sử dụng
- Hoạt động offline trên máy tính cá nhân

## Yêu cầu

- Windows 10/11
- RAM trên 8Gb

## Sử dụng

1. Mở ứng dụng.
2. Nhập văn bản cần đọc.
3. Chọn giọng nói hoặc clone từ audio mẫu.
4. Nhấn tạo âm thanh và lưu file.

## Model hỗ trợ

- VieNeu-TTS-v3-Turbo (int8 · nhanh)
- VieNeu-TTS-v3-Turbo (fp32 · chất lượng cao)
- ZeroTTS (CPU)
